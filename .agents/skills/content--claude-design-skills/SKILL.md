# Claude Design Skills

## Overview
Claude Design Skills provides a masterclass framework for designing world-class, premium, and functional web applications. It eliminates generic "AI slop" in favor of intentional visual hierarchy, bespoke typography, harmonious HSL color palettes, organic textures, micro-interactions, and accessible, responsive layouts.

## Anti-Rationalization Table

| Rationalization | Reality |
|---|---|
| "A generic theme is good enough for now" | Visual quality and tactile feedback directly dictate user retention and immersion. |
| "Let's add purple gradients everywhere" | Avoid cliché AI design tropes (purple-on-dark, particle meshes). Use brand-tailored, authentic palettes. |
| "Desktop-only layout is fine" | Fluid responsiveness and container queries ensure flawless performance across mobile, tablet, and widescreen. |
| "Static buttons don't need micro-interactions" | Tactile hover states, active depth, and smooth spring transitions bring interfaces alive. |

## Core Design Principles

1. **Function-Driven Design**:
   - Every layout decision must serve the user's primary goal with zero friction.
   - Clean information architecture with logical content groupings.

2. **Bespoke Typography & Hierarchy**:
   - Curated font pairings (e.g., *Cinzel* for majestic fantasy headers, *IBM Plex Sans* or *Inter* for crisp body text).
   - Strict tracking, letter-spacing, and line-height ratios tailored to each size.

3. **Harmonious HSL & P3 Color Palettes**:
   - Multi-layered surfaces using subtle opacities and backdrop blurs (`rgba` / `hsla`).
   - Rich accents (e.g., Royal Gold `#d4af37`, Radiant Amber `#f59e0b`, Mythic Purple `#c084fc`, Emerald `#10b981`).

4. **Tactile Micro-Interactions**:
   - Smooth hover scaling (`transform: translateY(-2px)`), active compression (`scale(0.98)`), and glowing borders on focus.
   - Fluid keyframe animations for pulse, particle sparks, and level-up milestones.

5. **Anti-Cliché Rules**:
   - No generic purple-on-black templates.
   - No untracked oversized headlines.
   - No flat textureless grey rectangles.

## When to Use
- Designing new web views, dashboards, gaming HUDs, or product landing pages.
- Refactoring clunky, uninspired, or generic frontend components.
- Polishing typography, spacing tokens, and visual contrast for maximum accessibility.
