2. Seguir cada ação pelo fluxo de produção até o serviço, estado persistido e resultado observável; usar dados descartáveis.
3. Conferir testes e relatórios existentes sem tratá-los como prova de UI ou de execução real quando não exercitam esse caminho.

6. Registrar para cada subtela o que foi exercitado, defeitos reproduzidos, alterações, verificações e bloqueios concretos.
